# Fluxo — Despesas

Aplicação de gestão de despesas pessoais com suporte a PWA (instalável no telemóvel e PC).

## Acesso
🔗 **[Abrir app](https://SEU-USERNAME.github.io/fluxo-despesas)**

## Funcionalidades
- Dashboard com KPIs mensais e gráficos
- Registo e gestão de despesas
- Compromissos fixos mensais
- Análise anual por categoria
- Exportação para Excel
- Autenticação com Firebase
- Instalável como app (PWA)

## Instalar como app

**Android (Chrome):** Abre o link → menu ⋮ → *Adicionar ao ecrã inicial*

**iPhone (Safari):** Abre o link → botão partilhar → *Adicionar ao ecrã de início*

**PC (Chrome/Edge):** Abre o link → ícone de instalar na barra de endereço

## Stack
- HTML/CSS/JS vanilla
- Firebase Auth + Firestore
- Chart.js
- SheetJS (exportação Excel)
